Connect your ESPN league

Saved on this device only.

Finding the League ID

  1. Open the league on fantasy.espn.com in a web browser.
  2. The address bar has leagueId=1234567 — that number is it.

When you need the relay

If the league is private (the default on ESPN), or the league won't load directly, ESPN won't hand the data to a browser app. The fix is a tiny Google Apps Script relay — setup steps are in the README under “Fantasy relay”.
